## 📘 Лабораторная работа 1: Основы линейной регрессии и первичный анализ данных (EDA)

### 🎯 Что нужно сделать (Задания)
1. **Задание 1 (Расчетное)**:
   - Выполнить аналитический расчет предсказаний линейной регрессионной модели для тестовых векторов признаков.
2. **Задание 2 (Линейная регрессия)**:
   - Реализовать функцию `linear_regression_solution(ws, vectors)` без использования сторонних ML-библиотек.
   - Для каждого вектора $x = (x_1, \dots, x_m)$ рассчитать предсказание:
     $$\hat{y} = w_0 + \sum_{i=1}^{m} w_i \cdot x_i$$
   - Вернуть целочисленные предсказания для всей выборки.
3. **Задание 2.1 (Метрика MAE/MAD)**:
   - Реализовать функцию `mean_absolute_difference_solution(real, predictions)` для оценки качества модели:
     $$\text{MAD} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$
4. **Задания 3–6 (Работа с таблицами и библиотекой Pandas)**:
   - Загрузить данные о фильмах из [`movies_data.csv`](./ЛР1/movies_data.csv) и [`movies_budget.csv`](./ЛР1/movies_budget.csv).

   - Сформировать новые признаки (чистая прибыль = `Сборы - Бюджет`, рентабельность).
   - Выполнить группировку и расчет агрегированных метрик (суммарные и средние сборы, число картин по категориям).
5. **Задания 7–8 (Визуальный анализ и распределения)**:
   - По датасету [`many_factors_data.csv`](./ЛР1/many_factors_data.csv) построить парные диаграммы рассеяния (`pairplot`/`scatterplot`) и определить явные и скрытые зависимости между признаками $A, B, C, D, E$.
   - По датасету [`uniform_and_not_data.csv`](./ЛР1/uniform_and_not_data.csv) исследовать распределения признаков и выявить переменные с равномерным законом распределения.

## 📗 Лабораторная работа 2: Подготовка факторов (Feature Engineering)

### 🎯 Что нужно сделать (Задания)
1. **Задание 1 (Словарь категорий)**:
   - Реализовать подсчет частот уникальных категориальных значений в столбце с помощью структуры данных `dict`.
2. **Задания 2–3 (One-Hot / Бинарное кодирование)**:
   - Реализовать функцию `categorical_to_binary_solution(data, categorical_column)`, которая преобразует категориальный фактор в набор бинарных колонок (`0` / `1`) для каждого уникального класса без использования высокоуровневых оберток.
3. **Задание 4 (Целевое кодирование — Target Encoding)**:
   - Реализовать функцию `target_coding_solution(data, categorical_column, target_column)`.
   - Заменить каждое категориальное значение средней величиной целевой переменной по этой категории:
     $$\hat{x}_{cat} = \frac{1}{|S_{cat}|} \sum_{i \in S_{cat}} y_i$$
4. **Задания 5–6 (Стандартизация признаков)**:
   - Реализовать функцию `standard_deviation_solution(column)` для расчета среднеквадратического отклонения:
     $$\sigma = \sqrt{\frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})^2}$$
   - Реализовать функцию `standartize_column_solution(column)` для Z-масштабирования числовых факторов:
     $$z_i = \frac{x_i - \bar{x}}{\sigma}$$
5. **Задания 7–9 (Корреляционный анализ)**:
   - Реализовать функцию `correlation_solution(x, y)` для вычисления выборочного коэффициента корреляции Пирсона $r_{xy}$.
   - Реализовать `correlation_one_line_solution` и `correlation_table_solution` для генерации полной матрицы попарных корреляций числовых столбцов таблицы.

## 📙 Лабораторная работа 3: Выбор и создание модели (Перцептрон и MLP)

### 🎯 Что нужно сделать (Задания)
1. **Задание 1 (Прямой проход перцептрона)**:
   - Реализовать функцию `perceptron_classify_solution(ws, vectors)`, моделирующую работу однослойного искусственного нейрона с функцией активации $\text{sign}(z)$:
     $$\hat{y} = \text{sign}\left(w_0 + \sum_{j=1}^m w_j x_j\right), \quad \text{где } \text{sign}(z) = \begin{cases} +1, & z \ge 0 \\ -1, & z < 0 \end{cases}$$
2. **Задание 2 (Алгоритм обучения перцептрона)**:
   - Реализовать функцию `perceptron_train_solution(data, max_steps)`, обучающую перцептрон правилу Розенблатта.
   - При неверной классификации объекта корректировать вектор весов:
     $$w \leftarrow w + y_i \cdot x_i$$
   - Обучать модель до безошибочной классификации обучающей выборки либо до исчерпания лимита итераций.
3. **Задание 3 (Многослойный перцептрон — MLP)**:
   - Реализовать функцию `multilayer_perceptron_solution(weights, vector)`.
   - Выполнить прямое распространение сигнала (Forward Propagation) через скрытый слой нейронов и выходной слой.
   - Решить задачу разделения нелинейных логических функций (включая функцию исключающего ИЛИ — XOR).

## 🟣 Лабораторная работа 5: Подбор оптимальных параметров модели

### 🎯 Что нужно сделать (Задания)
1. **Задание 1 (Поиск по сетке — Grid Search)**:
   - Реализовать функцию `grid_search_solution(model_class, param_grid, train_data, val_data)`.
   - Организовать полный перебор конфигураций признаков и гиперпараметров модели линейной регрессии на данных [`grid_search_test_data.csv`](./Лабораторная%20работа%205.%20Подбор%20оптимальных%20параметров%20модели/grid_search_test_data.csv) для нахождения минимальной ошибки на валидации.
2. **Задание 2 (Метод дихотомии)**:
   - Реализовать функцию `dichotomous_search_solution(f, a, b, eps)` для нахождения одномерного минимума выпуклой функции на отрезке $[a, b]$ путем последовательного половинного деления отрезка.
3. **Задание 3 (Градиентный спуск — Gradient Descent)**:
   - Реализовать функцию `gradient_descent_solution(grad_f, x_0, alpha, eps)` для минимизации функции двух переменных:
     $$x^{(t+1)} = x^{(t)} - \alpha \cdot \nabla f(x^{(t)})$$
   - Итеративно двигаться в сторону антиградиента до выполнения условия $\|x^{(t+1)} - x^{(t)}\| < \varepsilon$.
4. **Задание 4 (Метод имитации отжига — Simulated Annealing)**:
   - Реализовать функцию `simulated_annealing_solution(f, x_0, t_0, lam, eps, random_gen)`.
   - Использовать стохастический переход в случайную окрестность с вероятностью принятия худшего состояния по критерию Метрополиса:
     $$P(\Delta E) = \exp\left(-\frac{\Delta E}{T}\right)$$
   - Понижать температуру $T \leftarrow \lambda \cdot T$ до достижения $T < \varepsilon$.
   - Найти глобальный минимум тестовой невыпуклой функции $g(x)$ и функции Вейерштрасса.
